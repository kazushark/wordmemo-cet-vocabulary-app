# 词笺 WordMemo

词笺 WordMemo 是一个面向 CET-4、CET-6 等英语备考场景的离线优先生词学习应用。项目使用原生 JavaScript、HTML、CSS 和 Node.js 构建，无需后端服务；单词库、学习记录、收藏状态和记忆统计均保存在浏览器 `localStorage` 中。

这个项目的目标不是做一个简单单词列表，而是模拟真实备考中的生词录入、释义确认、错词反复复习和记忆数据追踪流程。

## 项目亮点

- 离线词库匹配：输入英文单词后自动匹配释义、音标和中英例句。
- 多义项确认：支持一词多义勾选，入库前可手动编辑释义和例句。
- 词形还原：支持 `ing`、`ed`、复数等词形映射，例如从变形词匹配到原形释义。
- 相近词建议：未精确命中时提示候选词，并允许用户手动补充释义。
- 自适应学习队列：学习时优先抽取未学习词和高错误率词，比例约为 `3:2:2`。
- 错词强化：选择“不记得”的词会随机回到本轮队列，直到连续三次选择“记得”。
- 记错纠正：选择“记得”后若发现记错，可在详情页撤销本次正确记录。
- 记忆统计：按单词累计正确、未记得、提示次数，并计算记忆正确率。
- 星标学习：可收藏重点词，并单独学习星标单词。
- 自动分库：每 300 个录入词自动开启一个新词库，可按全部、星标或单独词库学习。
- 本地优先：学习记录只保存在当前浏览器，不上传个人数据。

## 技术栈

- 原生 JavaScript ES Modules
- HTML5 / CSS3
- Node.js 静态服务器
- Node.js test runner
- `localStorage` 本地持久化
- JSON / CSV 数据清洗与索引生成

## 功能模块

### 单词录入

用户输入单词后，应用会在本地词库中查询：

- 命中精确词条时，展示推荐释义、音标和例句。
- 命中原形词时，提示已按原形匹配。
- 未命中时，展示相近词建议，并提供手动输入框。
- 用户确认后，词条进入本地学习库。
- 可在录入确认弹窗中直接星标该词。

### 单词学习

用户可选择学习范围：

- 全部词库
- 星标单词
- 指定单词库

每轮学习会按指定数量抽取单词。答题前只展示英文单词，不展示中文释义。用户可选择：

- `记得`：若首次出现即记得，本轮不再出现。
- `不记得`：重新插入本轮后续随机位置，之后需连续三次记得。
- `提示`：展示英文例句，该次计为未记得。
- `记错了`：在详情页撤销刚才的“记得”，改按“不记得”处理。

### 数据统计

每个词会记录：

- 正确次数
- 未记得次数
- 提示次数
- 记忆正确率
- 最近学习状态
- 星标状态
- 所属单词库

## 运行项目

```bash
npm start
```

然后打开：

```text
http://localhost:4173
```

运行测试：

```bash
npm test
```

重新生成浏览器词库索引：

```bash
npm run build:data
```

重新构建前请先按 `data/sources/README.md` 放置上游源数据。

## 测试覆盖

项目使用 Node.js 内置 test runner 覆盖核心逻辑：

- 单词匹配与编辑距离建议
- 多义项数据结构
- 学习队列与错词重排
- 记忆正确率统计
- 星标词筛选
- 每 300 词自动分库
- 未学习、高错误率、一般词按比例抽取

## 数据来源与许可说明

- [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary)：参考 CET4/CET6 词表、中文释义、音标和中英例句。
- [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)：参考英汉词典字段、补充词条和词形还原数据。
- [excing/find-roots-of-word](https://github.com/excing/find-roots-of-word)：参考词根词缀数据，用于实验性的构词拆解提示。

公开仓库不包含大体积的上游原始词库副本；页面运行使用生成后的 `public/data/`。如需本地重新构建数据，请按 `data/sources/README.md` 准备源文件。对外发布、再分发或商业使用词典资料前，应再次核对各上游项目的许可与署名要求。
