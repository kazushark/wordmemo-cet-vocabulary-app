# Source Data

This directory is intentionally kept light in the public repository.

The app runs from generated browser data in `public/data/`. To rebuild that data locally, place the upstream source files under these folders:

- `data/sources/kylebing/`: CET word and sentence JSON files from `KyleBing/english-vocabulary`.
- `data/sources/ecdict/`: `ecdict.csv` and `lemma.en.txt` from `skywind3000/ECDICT`.
- `data/sources/excing/`: `roots-and-affixes.csv` from `excing/find-roots-of-word`.

Please check each upstream project's license before redistributing the source datasets.
